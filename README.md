# 图像显示与格式处理工具 V1.0

一个基于 `PyQt5 + numpy + Pillow` 的桌面工具，用于：

- 浏览并显示常规图片与多种 raw 数据格式
- 在常规图片与 raw 格式之间做转换
- 在界面中进行缩放、平移、选点取值与格式观察

---

## 主要功能

- **文件浏览与显示**
  - 支持打开单文件、打开文件夹、拖拽文件打开
  - 左侧目录树浏览，右键支持“刷新文件夹 / 关闭文件夹”
  - 刷新时会同步新增/删除文件，必要时自动清空右侧显示

- **图像显示与交互**
  - 常规图片：`png/jpg/jpeg/bmp/webp`
  - raw 自动识别或手动指定格式显示
  - `Ctrl + 鼠标滚轮` 缩放；放大/缩小/100%/适应窗口
  - 图像大于视图时显示水平/垂直滚动条
  - `Shift + 左键拖动` 平移视图（小手光标）
  - 左键点选像素后，底部状态栏显示坐标与对应格式数值
  - 右键或 `Esc` 取消选点

- **格式转换（处理菜单 -> 转为格式）**
  - 输入：常规图片
  - 输出：多种 raw 格式，支持自定义输出分辨率与输出目录
  - 对偶数宽高有要求的格式会进行校验

- **界面与状态**
  - 深色/浅色主题切换
  - 底部栏实时显示：文件路径 | 显示格式 | 缩放比例 | 选点信息

## 当前支持格式

### 转换输出 / raw 显示支持

- `rgbpack`
- `rgbplanar`
- `nv12`
- `nv21`
- `nv16`
- `nv61`
- `yuv422yuyv`
- `yuv422yvyu`
- `yuv422vyuy`
- `yuv422uyvy`
- `yuv444p`
- `yuv422p`
- `yuv420p`
- `yonly`

### 常规图片输入支持

- `png`
- `jpg`
- `jpeg`
- `bmp`
- `webp`
