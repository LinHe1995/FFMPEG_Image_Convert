# 图像显示与格式处理工具 V1.1

一个基于 `PyQt5 + numpy + Pillow` 的桌面工具，用于：

- 浏览并显示常规图片与多种 raw 数据格式
- 在常规图片与 raw 格式之间做转换
- 在界面中进行缩放、平移、选点取值与格式观察

---

## 主要功能

- **文件浏览与显示**
  - 支持打开单文件、打开文件夹、拖拽文件打开
  - 左侧目录树浏览，右键支持「刷新文件夹 / 关闭文件夹」
  - 刷新时会同步新增/删除文件，必要时自动清空右侧显示

- **图像显示与交互**
  - 常规图片：`png/jpg/jpeg/bmp/webp`（目录树中亦支持 gif）
  - raw 自动识别或手动指定格式显示
  - `Ctrl + 鼠标滚轮` 缩放；放大/缩小/100%/适应窗口
  - 图像大于视图时显示水平/垂直滚动条
  - `Shift + 左键拖动` 平移视图（小手光标）
  - 左键点选像素后，底部状态栏显示坐标与对应格式数值
  - 右键或 `Esc` 取消选点

- **格式转换（处理菜单 → 转为格式）**
  - 输入：常规图片（png/jpg/jpeg/bmp/webp）
  - 输出：多种 raw 格式，支持自定义输出分辨率与输出目录
  - `argb4444` / `argb1555` 支持设置整图 Alpha（0–255）
  - 对偶数宽高有要求的格式会进行校验

- **界面与状态**
  - 深色/浅色主题切换
  - 底部栏实时显示：文件路径 | MD5 | 显示格式 | 缩放比例 | 选点信息

## 当前支持格式

### 转换输出 / raw 显示支持

- `rgbpack`
- `rgbplanar`
- `argb4444`（每像素 16 位，A4R4G4B4，小端；转为格式对话框可设 Alpha 0–255）
- `argb1555`（每像素 16 位，A1R5G5B5，小端；Alpha ≥128 记为不透明位）
- `nv12`
- `nv21`
- `nv16`
- `nv61`
- `yuv422yuyv`
- `yuv422yvyu`
- `yuv422vyuy`
- `yuv422uyvy`
- `yuv444p`
- `yuv422p`
- `yuv420p`
- `yonly`

### 常规图片输入支持

- `png`
- `jpg`
- `jpeg`
- `bmp`
- `webp`

## 环境要求

- Windows（项目当前主要面向 Windows 使用）
- Python `3.11+`（建议）

依赖见 `requirements.txt`：

- `PyQt5>=5.15`
- `PyQt5-tools>=5.15`
- `numpy>=1.24`
- `Pillow>=10.0`

---

## 安装依赖

在项目根目录执行：

```bash
python -m pip install -r requirements.txt
```

---

## 本地运行（源码方式）

```bash
python run.py
```

或：

```bash
python src/main.py
```

推荐使用 `run.py`，其包含启动异常弹窗与入口封装。

---

## 打包 EXE

项目提供一键脚本：

```bat
build_exe.bat
```

脚本会自动完成：

1. 检查 Python
2. 检查/安装 PyInstaller
3. 从 `ui/img_icon.png` 生成 `ui/img_icon.ico`
4. 清理历史构建产物
5. 执行 PyInstaller 单文件打包
6. 重命名输出为中文版本名

默认输出文件在：

- `dist/图像显示与格式处理工具V1.1.exe`

## 常见说明

- 状态栏路径显示使用 `/`，便于跨平台观感与阅读。
- 打开文件后状态栏显示该文件的 MD5（文件内容哈希）。
- 选点坐标始终基于图像坐标系（左上角为 `(0,0)`），不受滚动和平移影响。
- 默认缩放为非平滑（最近邻）以便观察像素；可在「查看」菜单切换平滑显示。
- 文件名含独立词 `rgb`（如 `512x256_rgb.bin`）自动识别为 `rgbpack`；含 `rgbp` 识别为 `rgbplanar`。
